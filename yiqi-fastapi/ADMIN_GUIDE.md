# 一起呦管理系统使用指南

## 🎯 系统概述

这是一个基于FastAPI + Starlette-Admin构建的现代化管理后台，完全替代了原Django的xadmin功能。

## 🚀 快速启动

### 1. 启动服务
```bash
# 方法1：使用启动脚本
python start_server.py

# 方法2：直接使用uvicorn
python -m uvicorn app.main:app --host 0.0.0.0 --port 8001 --reload
```

### 2. 访问管理界面
- **URL**: http://localhost:8001/YiqiAdmin0001shujian/
- **用户名**: admin
- **密码**: admin123456

## 📋 功能模块

### 👥 用户管理
- **功能**: 用户档案管理、权限设置
- **特性**: 搜索、排序、分页
- **字段**: 姓名、昵称、手机号、性别、地区等

### 🏷️ 活动类型管理
- **功能**: 活动分类管理
- **特性**: 排序设置、启用/禁用
- **字段**: 类型名称、简介、排序号

### 📅 活动管理
- **功能**: 活动发布、审核、编辑
- **特性**: 审核状态管理、草稿功能
- **字段**: 标题、内容、时间、地点、人数限制等

### 📝 活动报名管理
- **功能**: 报名用户信息管理
- **特性**: 用户类型区分（发起人/参与者）
- **字段**: 真实姓名、微信号、报名时间

### 🔗 分享设置管理
- **功能**: 不同页面的分享配置
- **特性**: 页面类型分类管理
- **字段**: 分享标题、图片、页面类型

### ⭐ 用户收藏管理
- **功能**: 用户收藏数据统计
- **特性**: 时间排序、关联查询

### ⚠️ 举报管理
- **功能**: 用户举报内容处理
- **特性**: 举报理由搜索
- **字段**: 举报用户、被举报活动、举报理由

### 💬 评论管理
- **功能**: 用户评论审核
- **特性**: 内容搜索、时间排序
- **字段**: 评论内容、用户、活动、父评论

### 📮 反馈管理
- **功能**: 用户反馈处理
- **特性**: 处理状态管理
- **字段**: 反馈标题、内容、处理状态

### 🔧 系统用户管理
- **功能**: 系统账户管理
- **字段**: 用户名称、简介、用户类型

### 📢 系统消息管理
- **功能**: 系统消息推送管理
- **特性**: 阅读状态跟踪
- **字段**: 消息标题、内容、接收用户、阅读状态

## 🔐 权限说明

- **管理员登录**: 需要设置 `is_admin=True` 的用户
- **密码认证**: 使用bcrypt加密存储
- **Session管理**: 基于Starlette的session机制

## ⚙️ 技术架构

- **后端框架**: FastAPI
- **管理界面**: Starlette-Admin 0.15.1
- **数据库**: MySQL + SQLAlchemy
- **认证**: Session + bcrypt
- **模板引擎**: Jinja2

## 📝 常用操作

### 创建新管理员
```python
# 运行脚本创建管理员
python create_admin_user.py
```

### 修改管理员密码
1. 登录数据库
2. 更新 `users_userprofile` 表中的 `hashed_password` 字段

### 添加新的管理视图
1. 继承 `SQLAlchemyModelView` 类
2. 设置模型和配置属性
3. 在 `admin.py` 中注册视图

## 🚨 注意事项

- 首次登录后请及时修改默认密码
- 所有敏感操作都有日志记录
- 定期备份数据库数据
- 生产环境请关闭debug模式

## 🆘 故障排除

### 无法访问admin界面
- 检查服务是否正常启动
- 确认端口8001没有被占用
- 检查数据库连接是否正常

### 登录失败
- 确认用户名为 `admin`
- 确认密码为 `admin123456`
- 检查用户的 `is_admin` 字段是否为 `True`

### 数据库连接错误
- 检查 `.env` 文件中的数据库配置
- 确认MySQL服务正在运行
- 验证数据库用户权限

## 📞 技术支持

如有问题，请检查：

2. 数据库连接状态
3. 依赖包版本兼容性
